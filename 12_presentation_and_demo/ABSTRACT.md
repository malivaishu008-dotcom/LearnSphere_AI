# Abstract - LearnSphere AI

LearnSphere AI is a student-centred study operating system developed during the MindForgeAI AIML Internship at Chatake Innoworks Pvt. Ltd. The application addresses the problem of fragmented academic workflows by bringing study planning, notes, syllabus records, timetable entries, previous-year questions, practice checks, uploaded resources, focus logging, reflection, and learning signals into one clean web workspace.

The project is implemented as a full-stack MVP using Flask, SQLite, JWT authentication, modular academic APIs, and a responsive HTML/CSS/JavaScript frontend. The system is designed around a simple learning loop: capture academic material, plan focused tasks, practise active recall, reflect on progress, and adapt the next study session.

LearnSphere AI uses responsible AI language throughout the product. Study-coach responses are positioned as assistance, and predicted marks are labelled as indicative learning scenarios rather than certain or diagnostic academic results. The project also follows a privacy-aware integration policy: students should never be asked for third-party provider passwords, and future AI integrations should use server-side secrets or approved OAuth flows.

The result is a deployable internship-quality educational technology project with backend integration, frontend workspace, testing, deployment assets, documentation, and a clear roadmap for production hardening.
